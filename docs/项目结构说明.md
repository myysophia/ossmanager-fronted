## 🛡️ 安全中间件说明

### middleware.ts

**位置：** `src/middleware.ts`

**功能：** 为所有 API 请求添加安全保护

**核心功能：**

#### 1. 速率限制
```
默认配置：60秒内最多100个请求
超过限制：返回 429 Too Many Requests
```

#### 2. 可疑请求检测
监控以下模式：
- 路径遍历：`../`
- XSS 注入：`<script>`
- SQL 注入：`union select`
- 代码执行：`exec()`
- 原型污染：`__proto__`

#### 3. 安全响应头
自动添加：
- X-Frame-Options
- X-Content-Type-Options
- X-XSS-Protection
- Content-Security-Policy
- Referrer-Policy

#### 4. 安全日志
记录所有可疑请求到控制台

**配置方式：**
```typescript
// 修改速率限制配置
const RATE_LIMIT_CONFIG = {
  windowMs: 60 * 1000,  // 时间窗口
  maxRequests: 100,      // 最大请求数
};
```

**生效范围：** 所有 `/api/*` 路由
