# 环境变量配置指南

本文档说明项目中使用的环境变量及其安全配置方法。

---

## 📋 配置文件说明

### 环境配置文件

创建以下文件来配置不同环境：

```
.env.local          # 本地开发环境（不提交到 Git）
.env.test           # 测试环境配置
.env.production     # 生产环境配置
```

⚠️ **重要提示：** 
- `.env.local` 永远不要提交到代码库
- 生产环境的敏感信息应通过服务器环境变量设置
- 将 `.env*.local` 添加到 `.gitignore`

## 🔧 环境变量列表

### API 配置

```bash
# API 基础地址
NEXT_PUBLIC_API_URL=http://localhost:8080/api/v1

# 说明：
# - NEXT_PUBLIC_ 前缀的变量会暴露到客户端
# - 开发环境：http://localhost:8080/api/v1
# - 测试环境：https://test-api.yourdomain.com/api/v1
# - 生产环境：https://api.yourdomain.com/api/v1
```

### 安全配置

```bash
# 允许的跨域来源（CORS）
ALLOWED_ORIGIN=https://yourdomain.com

# 说明：
# - 生产环境必须设置为具体域名，禁止使用 *
# - 多个域名用逗号分隔：https://app1.com,https://app2.com
# - 开发环境可以使用：http://localhost:3000
```

```bash
# JWT 密钥（服务端使用）
JWT_SECRET=your-secret-key-here

# 生成强密钥的方法：
# openssl rand -base64 32
# 或使用在线工具：https://www.uuidgenerator.net/
```

```bash
# 会话密钥
SESSION_SECRET=your-session-secret-here

# 说明：用于会话加密，必须是强随机字符串
```

### 速率限制配置

```bash
# 速率限制时间窗口（毫秒）
RATE_LIMIT_WINDOW_MS=60000

# 时间窗口内最大请求数
RATE_LIMIT_MAX_REQUESTS=100

# 说明：
# - 默认：60秒内最多100个请求
# - 根据实际需求调整
# - API密集型应用可以适当提高
```

### 文件上传配置

```bash
# 最大文件大小（字节）
MAX_FILE_SIZE=10485760

# 允许的文件类型（MIME types）
ALLOWED_FILE_TYPES=image/jpeg,image/png,image/gif,application/pdf

# 说明：
# - MAX_FILE_SIZE: 10485760 = 10MB
# - 根据业务需求调整允许的文件类型
```

### 环境标识

```bash
# 当前环境
NODE_ENV=development

# 可选值：
# - development: 开发环境
# - test: 测试环境
# - production: 生产环境
```

### 监控和日志

```bash
# 日志级别
LOG_LEVEL=info

# 可选值：debug | info | warn | error
# - development: debug
# - test: info
# - production: warn
```

```bash
# Sentry DSN（错误监控，可选）
SENTRY_DSN=https://xxx@xxx.ingest.sentry.io/xxx

# 说明：
# - 用于生产环境错误监控
# - 在 https://sentry.io 注册获取
```

### 功能开关

```bash
# 启用调试模式
DEBUG_MODE=false

# 说明：生产环境务必设为 false
```

```bash
# 启用安全日志
ENABLE_SECURITY_LOGS=true

# 说明：记录可疑请求和安全事件
```

## 📝 配置示例

### 开发环境 (.env.local)

```bash
# API配置
NEXT_PUBLIC_API_URL=http://localhost:8080/api/v1

# 安全配置
ALLOWED_ORIGIN=http://localhost:3000
JWT_SECRET=dev-secret-key-not-for-production
SESSION_SECRET=dev-session-secret

# 速率限制（开发环境可以放宽）
RATE_LIMIT_WINDOW_MS=60000
RATE_LIMIT_MAX_REQUESTS=1000

# 环境
NODE_ENV=development
DEBUG_MODE=true
ENABLE_SECURITY_LOGS=true
LOG_LEVEL=debug
```

### 测试环境 (.env.test)

```bash
# API配置
NEXT_PUBLIC_API_URL=https://test-api.yourdomain.com/api/v1

# 安全配置
ALLOWED_ORIGIN=https://test.yourdomain.com
JWT_SECRET=<强随机密钥>
SESSION_SECRET=<强随机密钥>

# 速率限制
RATE_LIMIT_WINDOW_MS=60000
RATE_LIMIT_MAX_REQUESTS=200

# 环境
NODE_ENV=test
DEBUG_MODE=false
ENABLE_SECURITY_LOGS=true
LOG_LEVEL=info
```

### 生产环境 (.env.production)

```bash
# API配置
NEXT_PUBLIC_API_URL=https://api.yourdomain.com/api/v1

# 安全配置（必须设置）
ALLOWED_ORIGIN=https://yourdomain.com
JWT_SECRET=<从密钥管理服务获取>
SESSION_SECRET=<从密钥管理服务获取>

# 速率限制（严格）
RATE_LIMIT_WINDOW_MS=60000
RATE_LIMIT_MAX_REQUESTS=100

# 文件上传（限制更严格）
MAX_FILE_SIZE=5242880
ALLOWED_FILE_TYPES=image/jpeg,image/png

# 环境
NODE_ENV=production
DEBUG_MODE=false
ENABLE_SECURITY_LOGS=true
LOG_LEVEL=warn

# 监控
SENTRY_DSN=https://xxx@xxx.ingest.sentry.io/xxx
```

## 🔒 安全最佳实践

### 1. 密钥管理

✅ **推荐做法：**
- 使用密钥管理服务（AWS Secrets Manager、Azure Key Vault 等）
- 使用强随机密钥生成器
- 定期轮换密钥
- 不同环境使用不同的密钥

❌ **避免做法：**
- 将密钥硬编码在代码中
- 将 `.env` 文件提交到 Git
- 在多个项目间共享密钥
- 使用弱密钥（如 "secret"、"password123"）

### 2. 环境隔离

```bash
# 开发环境
ALLOWED_ORIGIN=http://localhost:3000

# 测试环境
ALLOWED_ORIGIN=https://test.yourdomain.com

# 生产环境
ALLOWED_ORIGIN=https://yourdomain.com
```

确保每个环境的配置完全独立，避免互相影响。

### 3. 最小权限原则

只暴露必要的环境变量到客户端（使用 `NEXT_PUBLIC_` 前缀）：

```bash
# ✅ 可以暴露（非敏感信息）
NEXT_PUBLIC_API_URL=https://api.yourdomain.com

# ❌ 不要暴露（敏感信息）
JWT_SECRET=xxx  # 不要添加 NEXT_PUBLIC_ 前缀
```

### 4. 验证和验证

在代码中验证环境变量：

```typescript
// lib/config/env.ts
const requiredEnvVars = [
  'NEXT_PUBLIC_API_URL',
  'JWT_SECRET',
  'SESSION_SECRET',
];

requiredEnvVars.forEach((varName) => {
  if (!process.env[varName]) {
    throw new Error(`缺少必需的环境变量: ${varName}`);
  }
});
```

## 🔍 调试

### 查看当前环境变量

创建临时路由用于调试（仅开发环境）：

```typescript
// app/api/debug/env/route.ts
export async function GET() {
  if (process.env.NODE_ENV !== 'development') {
    return NextResponse.json({ error: 'Forbidden' }, { status: 403 });
  }
  
  return NextResponse.json({
    NODE_ENV: process.env.NODE_ENV,
    API_URL: process.env.NEXT_PUBLIC_API_URL,
    // 不要输出敏感信息
  });
}
```

访问 `http://localhost:3000/api/debug/env` 查看。
