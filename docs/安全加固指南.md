### 2. 中间件安全加固 ✅

已添加 `src/middleware.ts`，实现以下功能：

- **速率限制**：防止 DDoS 和暴力破解攻击
  - 默认：60秒内最多100个请求
  - 可通过修改 `RATE_LIMIT_CONFIG` 调整

- **可疑请求检测**：检测常见攻击模式
  - 路径遍历 (../)
  - XSS 注入 (<script>)
  - SQL 注入 (union select)
  - 代码执行 (exec()、constructor)
  - 原型污染 (__proto__)

- **安全响应头**：
  ```
  X-Frame-Options: DENY
  X-Content-Type-Options: nosniff
  X-XSS-Protection: 1; mode=block
  Referrer-Policy: strict-origin-when-cross-origin
  Content-Security-Policy: ...
  ```

- **请求日志**：记录所有可疑请求便于审计

## 🔧 CORS 策略优化

### 当前配置（需要优化）

`next.config.js` 中存在过于宽松的 CORS 配置：

```javascript
// ⚠️ 不推荐 - 允许所有来源
{ key: 'Access-Control-Allow-Origin', value: '*' }
```

### 推荐配置

```javascript
// ✅ 推荐 - 限制特定域名
async headers() {
  const allowedOrigin = process.env.NODE_ENV === 'production'
    ? 'https://yourdomain.com'
    : 'http://localhost:3000';
    
  return [
    {
      source: '/api/:path*',
      headers: [
        { key: 'Access-Control-Allow-Origin', value: allowedOrigin },
        { key: 'Access-Control-Allow-Credentials', value: 'true' },
        { key: 'Access-Control-Allow-Methods', value: 'GET,POST,PUT,DELETE,OPTIONS' },
        { key: 'Access-Control-Allow-Headers', value: 'Content-Type, Authorization' },
      ],
    },
  ];
}
```

配置环境变量 `.env.production`：

```bash
ALLOWED_ORIGIN=https://yourdomain.com
```

## 🛡️ 安全最佳实践

### 1. 输入验证

**所有用户输入都需要验证：**

```typescript
// ✅ 好的做法
const userInput = sanitize(request.body.data);
const validated = schema.parse(userInput);

// ❌ 不好的做法
const userInput = request.body.data; // 直接使用未验证的输入
```

### 2. 参数化查询

```typescript
// ✅ 使用参数化查询防止 SQL 注入
const result = await db.query(
  'SELECT * FROM users WHERE id = ?',
  [userId]
);

// ❌ 拼接 SQL 字符串
const result = await db.query(
  `SELECT * FROM users WHERE id = ${userId}`
);
```

### 3. 敏感数据处理

```typescript
// ✅ 不返回敏感信息
const { password, ...userWithoutPassword } = user;
return NextResponse.json(userWithoutPassword);

// ❌ 返回包含密码的完整用户对象
return NextResponse.json(user);
```

### 4. 认证和授权

```typescript
// ✅ 验证 token 并检查权限
const token = request.headers.get('Authorization');
const user = await verifyToken(token);
if (!user || user.role !== 'admin') {
  return NextResponse.json({ error: 'Forbidden' }, { status: 403 });
}

// ❌ 信任客户端发送的用户信息
const { userId } = await request.json();
// 直接使用 userId 进行操作
```

## 🔍 持续监控

### 1. 定期运行安全审计

添加到 CI/CD 流程：

```yaml
# .github/workflows/security.yml
name: Security Audit

on:
  push:
    branches: [main, develop]
  schedule:
    - cron: '0 0 * * *' # 每天运行

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Run npm audit
        run: npm audit --audit-level=moderate
```

### 2. 配置 Dependabot

```yaml
# .github/dependabot.yml
version: 2
updates:
  - package-ecosystem: "npm"
    directory: "/"
    schedule:
      interval: "daily"
    open-pull-requests-limit: 10
```

### 3. 监控日志

使用日志聚合工具（如 ELK、Datadog）监控：
- 速率限制触发事件
- 可疑请求
- 认证失败
- 异常错误
